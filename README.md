# WebScraper

A web scraping project.

## Description

This project contains web scraping tools and scripts. Testing on https://quotes.toscrape.com/ built specifically for programmers to safely test their web scrapers. 

## Installation

```bash
# Clone the repository
git clone https://github.com/camillac7/WebScraper.git
cd WebScraper
```

## Usage

```bash
# Run the scraper
python main.py
```

## Requirements

- Python 3.7+
- requests
- beautifulsoup4
- lxml

Install dependencies:
```bash
pip install -r requirements.txt
```
